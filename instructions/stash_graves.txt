#  Notes:
#  1. Read the general instructions in README.md.
#  2. 'stash_graves.py' must be run before 'dig-graves.py.'
#  3. For data integrity (if getting multiple groups), get a fresh copy of for all groups before running 'dig-graves.py.'
#  4. Every "information only" line in this file must start with a #.
#  5. By default, "log" appears by itself on a line. This will create a log file in the /logs folder. To not create a log for each run,
#     preceed "log" by a comment symbol (#) e.g. #log.
#  6. Be sure to read and follow the guidelines under the 'Schema' section below. Do not forget to create a unique abbreviation for each
#     cemetery (e.g. PRES, UMC, ...) and append it after the cemetery id (e.g. 2353265-PRES, 2136908-UMC, ...). This abbreviation
#     is used as the tab name on the final spreadsheet created by 'dig-graves.py.'
#  7. 'stash_graves.py' creates a local stash of 'Find a Grave' memorial pages for each cemetery.
#     Stashes are named by cemetery and located in the /stash folder. If you move or rename them, 'dig-graves.py' (which extracts
#     data from each stash and creates teh spreadsheet report) will fail.
#
#  Schema:
#   log = create a log file
#   cemetery_id-nickname : group, group, ...
#   cemetery_id = numeric Find a Grave cemetery ID
#   -nickname = cemetery abbreviation for spreadsheet tab name     *** This is required, you must create it: e.g. PRES, UMC, ... ***
#   valid groups = burial, parent, spouse, child, sibling, half-sibling
#   Colon (:) separates cemetery_id and groups
#   Comma (,) separates groups
#   cemetery_id without group(s) will convert to include all groups.
#
#  Examples:
#   2136908 : child
#   2136908 : burial, parent, spouse, child, sibling, half-sibling
#   2136908 (converts to ...)
#   2136908 : family (converts to ...)
#   2136908 : burial, parent, spouse, child, sibling, half-sibling.
